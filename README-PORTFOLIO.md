# 관리자 스타일 사진 → 디자이너 포트폴리오 자동 연동

## 설치
이 ZIP의 내부 파일/폴더를 기존 GitHub 저장소 루트에 병합하여 덮어쓰기하고 `main` 브랜치에 Push하세요. 전체 삭제나 새 Vercel 프로젝트 생성은 하지 마세요.

## 사용법
1. 홈페이지 관리자 로그인 → 스타일 탭 → 새 스타일 추가 또는 기존 스타일 수정.
2. 시술 카테고리, 제목, 설명 입력 → **담당 디자이너 선택** → 사진 선택 → 저장.
3. 사진은 기존 관리자 방식으로 압축되어 Firestore의 `site/styles`에 저장됩니다.
4. `/designers/seodan.html` 같은 디자이너 페이지에서 담당 디자이너에 해당하는 사진이 자동으로 보입니다. 메인페이지 디자이너 카드에도 최근 사진 최대 3장이 연결됩니다.
5. 기존에 저장된 스타일은 **수정**에서 담당 디자이너를 선택해야 연결됩니다.

## 주의
- 신규 공개 포트폴리오는 실제 시술 사진과 고객의 게시 동의를 확보한 경우에만 등록하세요.
- 사진은 Firestore 데이터 문서에 함께 보관되며 기존 서버는 전체 데이터 크기 850KB 초과 저장을 거부합니다. 사진이 누적되면 저장이 막힐 수 있으므로, 장기적으로 Firebase Storage 기반 업로드로 이전하는 편이 좋습니다.
- 관리자 설정/예약 링크/영업시간/이벤트 등 기존 내용은 수정하지 않았습니다.
- 정적 페이지의 새 사진은 브라우저에서 읽어 표시하는 것으로, 사진별 정적 SEO HTML 자동 생성이나 검색엔진의 즉시 색인까지 보장하지 않습니다.
- Firebase 실서버 연결 및 관리자 인증은 이 환경에서 검증할 수 없으므로 배포 후 실제 로그인·추가·수정·삭제 테스트가 필요합니다.
