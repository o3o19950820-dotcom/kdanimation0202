# 준오헤어 건대역2호점 업그레이드 패키지

대상 저장소: `o3o19950820-dotcom/kdanimation0202`

## 포함된 파일
- `face-shape-game.html`: 성별 대신 원하는 남성/여성 헤어스타일 카테고리, 얼굴형, 스타일 취향을 선택하는 미니게임
- `site-upgrade.js`: 메인에 게임 및 기존 추천도구 연결 카드, 실제 시술 Before/After 갤러리, 관리자 `시술 전후` 탭, 디자이너별 스타일 개수 링크 추가

## 업로드
1. 두 파일을 GitHub 저장소 **최상단(root)** 에 업로드.
2. 기존 `index.html`의 `</body>` 바로 **위**에 아래 한 줄만 추가:

```html
<script type="module" src="/site-upgrade.js"></script>
```

3. 커밋 후 Vercel에서 배포 완료 확인.
4. `https://junokd02.com/face-shape-game.html` 확인.
5. 홈페이지 관리자 로그인 > `시술 전후` 탭에서 기존 스타일을 선택하고 사진·설명을 등록.
6. 스타일 데이터를 갱신하면 메인에 전후 갤러리가 나타남. 전후 사진이 등록되지 않았으면 갤러리가 숨겨짐.

## 중요
- 기존 `index.html`, `app.js`, `admin-ui.js`, `firebase.js`, `api/admin.js`를 교체하지 않습니다.
- 이전에 등록한 스타일의 `designerSlug`를 활용합니다. 해당 값이 없으면 관리자 기존 '스타일' 탭에서 담당 디자이너를 지정하세요.
- 전후 사진은 반드시 고객의 게시 동의를 받은 후 등록하세요.
- 저장은 기존 관리자 Firebase 로그인 + `/api/admin` 권한 검사를 사용합니다. 새로운 암호/환경변수는 필요 없습니다.
- 사진은 압축해서 기존 이미지 업로드 로직을 이용합니다. 큰 파일이거나 네트워크/서버 환경에 따라 저장 실패할 수 있습니다.
- 얼굴형 제안은 참고용이며 객관적인 진단·외모 평가가 아닙니다.
- **운영 중인 저장소에 즉시 덮어쓰지 않았습니다**. 업로드 전 커밋/백업을 만들어두세요.
- 라이브 배포 확인과 E2E 동작 테스트는 아직 완료하지 못했습니다.
