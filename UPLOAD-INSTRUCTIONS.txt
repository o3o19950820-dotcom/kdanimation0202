준오헤어 건대역2호점 시술사례 기능 업로드 안내

1. real-hair-cases.html 파일을 GitHub 저장소 최상위(root)에 업로드하세요. 동일 이름의 파일이 있다면 교체하세요.
2. GitHub index.html 파일을 Edit(연필 아이콘)으로 열어서 메뉴의 <a href="#styles">스타일</a> 바로 다음에 다음 한 줄을 추가하세요.
   <a href="/real-hair-cases.html">실제 시술사례</a>
3. index.html 맨 아래 </body> 바로 위에 아래 한 줄을 추가하세요. 기존 파일에 site-upgrade.js 참조가 이미 있다면 중복 추가하지 마세요.
   <script type="module" src="/site-upgrade.js"></script>
4. Commit changes → Vercel 배포 후 https://junokd02.com/real-hair-cases.html 방문.
5. 시술사례 페이지 하단에서 기존 관리자 계정으로 로그인 → 새 시술사례 등록 → 제목/디자이너/고객 고민/시술 설명/전후 사진 → 동의 확인 → 저장 및 공개.
6. 메인 홈페이지에서도 기존 관리자에 '시술 전후' 탭이 새로 생깁니다. 해당 탭은 site-upgrade.js에 이미 구현되어 있습니다.

주의: 새로운 비밀번호나 Firebase 설정은 필요 없습니다. 이 페이지는 기존 site/styles 문서를 재사용합니다. 관리자에서 기존 '스타일'을 수정하는 경우도 동일 데이터를 사용하므로 덮어쓰지 않도록 주의하세요. 공개 동의가 없는 사진은 등록하지 마세요.

기존 메인 홈페이지 전체 내용을 건드리지 않도록 index.html 전체 교체 파일은 제공하지 않습니다.
