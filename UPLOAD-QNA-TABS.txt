방법
- 기존 app.js를 새 app.js로 교체
- 기존 admin-ui.js를 새 admin-ui.js로 교체
- 다른 파일은 건드리지 않기
- 커밋 후 Vercel 배포 완료되면 사이트 새로고침

추가되는 기능
- Q&A 탭: 전체 / 커트 / 펌 / 컬러 / 케어 / 예약·가격 / 기타
- 탭별 질문 개수 표시
- 모바일에서는 탭 가로 스크롤
- 관리자 > FAQ에서 카테고리 선택 후 글 추가 가능
- 기존 글 수정 시 카테고리 변경 가능
- 기존 글 삭제 기능 유지
- 기존 카테고리 없는 글은 질문 문구를 기준으로 자동 분류해서 표시
- 한 번 수정 저장한 기존 글은 선택한 카테고리가 Firestore에 저장됨

그대로 유지되는 기능
- 관리자 로그인 / 로그아웃
- 기본설정
- 이벤트
- 디자이너
- 스타일
- 헤어TIP
- 블로그
- 고객문의
- 가격표 및 가격 API
- Firebase / Vercel 관리자 서버 설정

api/admin.js, firebase.js, firestore.rules, index.html, style.css, prices.js는 수정하지 않습니다.
