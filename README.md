# 준오헤어 건대역2호점 예약·콘텐츠 개선 패치

기존 `index.html`, Firebase 관리자, 문의기능, 사이트맵은 삭제하지 않고 HTML에 CSS/JS 참조만 추가합니다. **현재 원본 GitHub 저장소 코드를 직접 받지 못했기 때문에**, 자동 삽입되는 애드온 방식입니다. 배포 전에 반드시 미리보기에서 확인해 주세요.

## 설치 (Windows)
1. GitHub 저장소를 ZIP으로 내려받아 압축을 풉니다.
2. 이 압축파일의 `install.py`, `assets/`, `data/`를 **기존 `index.html`이 있는 폴더**에 복사합니다.
3. 그 폴더의 주소창에 `cmd` 입력 → `py install.py` 실행 (`py`가 없으면 `python install.py`).
4. 변경된 HTML과 새 `assets/juno-upgrade.*`, `data/site-config.json`을 GitHub에 업로드/커밋합니다.
5. Vercel 배포 이후 메인, 스타일, 디자이너, 관리자, 모바일 화면을 테스트합니다.

**주의:** `index.html`만 단독으로 교체하거나 본 ZIP 전체를 저장소 위에 덮어쓰지 마세요. `install.py`는 이미 삽입된 파일에는 중복 적용하지 않습니다. 수정 전 원본 HTML은 `.juno-upgrade-backup/`에 보관합니다(백업 폴더는 GitHub에 올리지 마세요).

## 설정: data/site-config.json
- `reservationUrl`: 현재는 홈페이지에서 사용 중인 네이버 지도 검색 주소입니다. **정확한 네이버 예약 URL을 확인한 뒤 교체**하면 버튼이 바로 예약 화면으로 이동합니다.
- `instagramUrl`: 공식 매장 인스타그램 URL (비워두면 버튼이 안 보임).
- `designerInstagram`: 디자이너별 본인 공개 인스타그램 링크. 예: `"seodan": "https://www.instagram.com/정확한아이디/"`.
- `cases`: 매장에서 촬영했고 게시 허락 받은 실제 시술 사진과 설명을 채워 주세요. `published: true`이고 `image`, `title`이 있는 사례만 노출됩니다. 사례를 지어내지 않습니다.

### 시술 사례 입력 예시(실제 사진·사실 확인 후 입력)
```json
{
  "style": "layered-cut",
  "designer": "seodan",
  "title": "중단발 레이어드컷 시술 사례",
  "image": "/images/cases/layered-cut-01.webp",
  "alt": "준오헤어 건대역2호점 중단발 레이어드컷 뒷모습",
  "description": "실제 시술 사진에 맞는 모발 상태, 디자인 과정, 손질 포인트를 입력하세요.",
  "published": true
}
```
위 객체를 `cases` 배열에 넣고, 사진 파일을 저장소 `/images/cases/`에 함께 올리면 해당 스타일 페이지, 해당 디자이너 페이지, 메인에서 연결된 사례가 보입니다. 이미지가 없으면 카드가 깨질 수 있으므로 파일 업로드를 먼저 확인하세요.

## 추가된 요소
- 모바일 하단 예약/이용 안내 바(기존 화면을 최대한 유지)
- 스타일 상세페이지 예약 CTA, 스타일별 별도 FAQ, 관련 디자이너 내부 링크
- 디자이너 상세페이지 예약 CTA, 관련 스타일 링크, 실제 인스타 링크(입력한 경우)
- 사진을 올린 경우에만 실제 시술 사례 카드 표시
- 공통 디자인 CSS. 기존 관리자와 Firebase 로직은 손대지 않음

## 중요: 실제 HTML 경로와 연결 확인
현재 공개 사이트를 기준으로 슬러그를 추정하여 매핑했습니다. 실제 페이지 파일 이름이 다른 경우 `assets/juno-upgrade.js`의 `styles` / `ds` 매핑 키를 실제 이름과 일치시키세요. 검색용 페이지와 관리자에서 `main` 태그가 없다면 패널이 본문 끝에 붙을 수 있습니다. 모바일 고정바의 '가격·이용 안내'는 `/#faq`로 연결되므로 기존 사이트에서 정확한 가격표 위치가 다르다면 URL을 바꿔 주세요.

## 게시 전 체크
- 네이버 버튼이 실제 예약 화면으로 이동하는지
- 디자이너·스타일 링크가 404 없이 열리는지
- 모바일에서 하단바가 다른 버튼을 가리지 않는지
- Firebase 로그인, 문의 등록 및 관리자 스타일 등록이 기존대로 되는지
- 개인정보·고객 얼굴 노출 동의 및 저작권 허락이 있는 사진인지
- 이벤트와 영업시간은 요청대로 수정하지 않았습니다
