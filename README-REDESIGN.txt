준오헤어 건대역2호점 - 브라운/아이보리 리디자인

이 ZIP은 현재 사이트의 Firebase 로그인 / 관리자 CMS / 비공개 고객문의 / API 구조를 그대로 유지한 채 디자인을 전면 교체한 버전입니다.

포함 기능
- 업로드한 실제 매장 사진 4장 적용
- 업로드한 검정/흰색 JUNO HAIR 건대역2호점 로고 적용
- 고동색 #4B2E20 / 아이보리 #F6F3EE / 블랙 #111111 디자인
- 모바일 반응형
- 관리자: 기본 문구, 네이버예약, 블로그, 주소/시간/전화, 메인/매장 사진, 이벤트, 디자이너, 스타일, 헤어TIP, FAQ, 고객문의 수정
- 디자이너 상세페이지 편집 기능 유지
- 기존 Firestore site/* 데이터 구조와 /api/admin 백엔드 유지

업로드 방법
1. 압축을 풉니다.
2. 안의 파일/폴더 전체를 현재 GitHub 저장소 root에 업로드하고 같은 이름은 덮어씁니다.
3. Commit changes.
4. 기존 Vercel 프로젝트가 같은 저장소를 보고 있다면 자동 배포됩니다.

중요
- 기존 Firebase 설정값은 그대로 들어 있습니다.
- 현재 Vercel에 Firebase Admin 환경변수가 이미 설정돼 있다면 그대로 작동합니다.
- 기존 디자이너/스타일/이벤트/FAQ 등의 Firestore 데이터는 삭제하지 않습니다. 새 디자인이 같은 site 문서를 그대로 읽습니다.
